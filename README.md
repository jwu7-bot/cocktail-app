# 🍸 Cocktail Explorer

A fun and interactive **Cocktail App** built with **Node.js, Express, and EJS**, allowing users to explore, search, and discover cocktail recipes from [TheCocktailDB API](https://www.thecocktaildb.com/).

---

## 🚀 Features

- 🎲 **Random Cocktail** — Get a surprise drink suggestion with one click.
- 🔍 **Search by Name** — Look up cocktails by their name.
- 🧃 **Search by Ingredient** — Find all drinks that include a specific ingredient.
- 🗂️ **Browse by Category** — Explore cocktails grouped by categories (e.g., "Ordinary Drink", "Cocktail", "Shot").
- 📖 **View Full Recipe** — Click *“View Recipe”* to see detailed instructions and ingredients.
- 📑 **Pagination** — Easily navigate large result lists.
- 🧱 **Responsive Grid Layout** — Works beautifully on desktop and mobile.

---

## 🧩 Tech Stack

- **Backend:** Node.js + Express
- **Frontend:** EJS templates + Bootstrap
- **Styling:** CSS / Bootstrap Grid
- **API:** [TheCocktailDB](https://www.thecocktaildb.com/api.php)

---

## ⚙️ Installation

1. **Clone this repository:**
   ```bash
   git clone https://github.com/jwu7-bot/cocktail-app.git
   cd cocktail-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   
3. **Run the app:**
   ```bash
   npm start
   ```

4. **Visit:**
   ```bash
   http://localhost:3000
   ```
